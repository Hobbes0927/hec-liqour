# hec-liqour

## Description
REDM liquor script, which allows for custom effects, gold cores, and thirst increases per drink


## Acknowledgements
This script is inspired by the original work of **PokeSer** from the project **poke_licor**.

Source: https://github.com/PokeSer/poke_licor


## Features
Interative drinking with props

Each drink can be customized to use different props

Select unique animations while drinking

Adjustable drunk time per drink

Adjustable gold core power length per drink (if enabled)

Adjustable thirst increase per drink


## Dependencies
vorp_core

vorp_inventory

A metabolism script (fx-hud, vorp-metabolism, or custom)


## Installation
Download the latest release from https://github.com/Hobbes0927/hec-liquor

Add the hec-liqour folder to your resources folder

Add ensure hec-liqour to your resources.cfg

Restart server
